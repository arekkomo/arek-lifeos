## Summary

HY-Motion 1.0 is an open-source text-to-3D human motion generation model developed by Tencent Hunyuan. Using a Diffusion Transformer architecture with flow-matching objectives, it generates realistic motion sequences from natural language prompts and exports them in skeleton-compatible formats for Blender, Unity, and Unreal.

## Features

- Text-to-motion generation via large Diffusion Transformer
- Billion-parameter and Lite (0.46B) model variants
- Three-stage training pipeline for scalable quality
- Batch inference and interactive Gradio interface
- Outputs skeleton and motion data usable in major 3D tools

## Use Cases

- Game and cinematic animation prototyping
- Research on 3D human motion generation
- Robotics motion data synthesis
- Low-cost motion capture alternative

## Installation

Clone repo, install dependencies via `pip install -r requirements.txt`, and run `local_infer.py` or `gradio_app.py` for inference.

## Other Info
