## Summary

ReCo is an open-source framework implementing the Region-Constraint In-Context Generation paradigm for instructional video editing. It features a large-scale dataset (ReCo-Data) and an evaluation benchmark (ReCo-Bench) for assessing video editing precision and generalization.

## Features

- Region-constraint in-context generation for editing precision
- 500K+ instruction-video pairs in ReCo-Data dataset
- ReCo-Bench benchmark for performance evaluation
- Example scripts for multiple editing tasks

## Use Cases

- Research in instruction-based video editing
- Training and benchmarking generative video editing models
- Evaluating region-based control methods in AI video systems

## Installation

Clone the repository, set up dependencies, and use provided scripts like reco_data_test_single.py to evaluate or visualize results.
