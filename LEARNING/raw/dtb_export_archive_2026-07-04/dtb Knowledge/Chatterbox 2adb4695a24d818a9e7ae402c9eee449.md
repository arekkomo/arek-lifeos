## Summary

Chatterbox supports 23 languages, zero‑shot voice cloning, exaggeration control and high‑quality aligned TTS generation, outperforming many closed‑source options.

## Features

- Multilingual support (23 languages)
- Zero‑shot voice cloning from reference audio
- Exaggeration/intensity control for expressive speech
- High‑alignment, large dataset training

## Use Cases

Voice over for content/films, multilingual dubbing, AI voice agents, clone speaker style for narration.

## Installation

pip install chatterbox‑tts, or git clone https://github.com/resemble-ai/chatterbox.git and pip install -e . Example: import and model.generate(text) per the README. ([github.com](https://github.com/resemble-ai/chatterbox?utm_source=chatgpt.com))
