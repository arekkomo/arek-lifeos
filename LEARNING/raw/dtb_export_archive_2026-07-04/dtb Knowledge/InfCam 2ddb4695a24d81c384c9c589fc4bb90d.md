## Summary

InfCam is an AI-driven video generation framework that enables precise camera-controlled outputs via infinite homography warping. It removes the need for depth estimation while maintaining accurate camera motion fidelity, making it ideal for creative and research applications in controllable video generation.

## Features

- Infinite homography conditioning for camera trajectory control
- No depth estimation required
- Integrates Wan2.1 base model and UniDepth for optional enhancements
- High fidelity adherence to camera poses
- Includes training and inference scripts

## Use Cases

- Create videos with realistic camera motion
- Enhance post-production workflows for VFX or filmmaking
- Research controllable video generation and motion conditioning

## Installation

Clone the repository, install dependencies (Python, PyTorch), download pretrained Wan2.1 and InfCam checkpoints, and run provided training/inference scripts.
