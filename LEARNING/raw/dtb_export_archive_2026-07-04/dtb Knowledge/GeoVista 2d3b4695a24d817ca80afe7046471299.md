## Summary

GeoVista is a research project implementing Web-Augmented Agentic Visual Reasoning for Geolocalization. It integrates visual understanding with web-based information retrieval to determine geographic locations from images using the GeoBench benchmark.

## Features

- Integrates visual reasoning with web search tools.
- Provides training, inference, and evaluation pipelines.
- Supports supervised fine-tuning and reinforcement learning.
- Includes vLLM deployment for efficient inference.

## Use Cases

- Research in multimodal AI agents for visual and web-integrated reasoning.
- Real-world image-based geolocalization tasks.
- Benchmarking on GeoBench.
- Developing hybrid AI agents combining vision and external tools.

## Installation

Set up a conda environment, install dependencies, configure API keys, and run example scripts for inference and evaluation.
