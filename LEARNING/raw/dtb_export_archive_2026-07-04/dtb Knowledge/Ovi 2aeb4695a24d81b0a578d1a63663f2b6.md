## Summary

Ovi is an open-source text-to-video and audio generation framework developed by Character AI. It produces synchronized visuals and sound directly from text or text+image prompts, allowing creators to generate audiovisual clips with natural coherence.

## Features

- Generates both video and audio in sync from text prompts
- Supports image conditioning and prompt-based audio control
- Output resolutions up to 960×960 and clip lengths of 5–10s
- Optional ComfyUI integration for visual workflows
- Apache 2.0 licensed

## Use Cases

- Filmmaking and content creation: generate fully audiovisual AI clips
- Rapid prototyping of scenes or shots with built-in sound
- Useful for VFX workflows or previsualization where sound cues matter

## Installation

Clone repo, install dependencies, run download_weights.py for checkpoints, and generate via CLI with text or image prompts. Requires ≥32GB VRAM GPU for small configs, 80GB for full models.

## Other Info

Released November 2025 by Character AI; merges text-to-video and text-to-audio diffusion into a unified model for coherent audiovisual storytelling.
