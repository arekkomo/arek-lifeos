## Summary

TurboDiffusion is an open-source project that accelerates video diffusion generation by 100–200× using optimized attention mechanisms, sparse computation, and distillation techniques. It maintains visual quality and supports real-time-level performance on modern GPUs like RTX 5090.

## Features

- Implements SageAttention and Sparse-Linear Attention (SLA)
- Utilizes rCM step distillation for efficient sampling
- Supports Wan2.1 and Wan2.2 pretrained models (480p and 720p)
- Compatible with quantized and unquantized checkpoints
- Open-source under Apache 2.0 with active research support

## Use Cases

- Fast text-to-video synthesis workflows
- Real-time video diffusion applications
- Research prototyping for video generation models
- Integration into creative pipelines or AI media tools

## Installation

Install via `pip install turbodiffusion` or clone and build from source. Includes inference scripts and model checkpoints.
