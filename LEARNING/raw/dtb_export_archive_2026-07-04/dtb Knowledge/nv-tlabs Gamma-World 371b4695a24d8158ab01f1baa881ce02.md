## About

γ-World generates a shared video world from multiple independent agent action streams at 24 FPS. Simplex Rotary Agent Encoding + Sparse Hub Attention for permutation-symmetric, linear-scaling multi-agent support.

**GitHub:** [https://github.com/nv-tlabs/Gamma-World](https://github.com/nv-tlabs/Gamma-World) (code coming soon)

**Paper:** [https://arxiv.org/abs/2605.28816](https://arxiv.org/abs/2605.28816)

**Project:** [http://research.nvidia.com/labs/sil/projects/gamma-world](http://research.nvidia.com/labs/sil/projects/gamma-world)

## Capabilities

- Multiple independently controllable agents in one generated world
- Simplex RoPE: permutation-symmetric agent encoding
- Sparse Hub Attention: O(n) vs O(n²) cross-agent attention
- 24 FPS via KV-cached causal student
- Zero-shot generalisation from 2 to 4 agents

## VFX / Filmmaking Use Cases

- Multi-camera/actor viewpoints in a generated virtual production environment
- Multi-character blocking previsualization in a generated world
- Aiah Syn: multiple AI agents performing in a shared generated stage
