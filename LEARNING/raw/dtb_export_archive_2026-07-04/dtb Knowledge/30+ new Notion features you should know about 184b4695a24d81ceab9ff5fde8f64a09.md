### **Key Takeaways**

- **Notion Calendar**: A unified calendar view that integrates Google calendars and Notion databases, with features like scheduling and multi-time zone support.  

- **Layout Builder**: Allows users to customize database page layouts, improving usability and organization.  

- **Automations Upgrade**: Introduced custom formulas, variable definitions, and webhook support, making automations more dynamic and powerful.  

- **Notion Forms**: A built-in form builder that links directly to databases, enabling workflows like client management without granting database access.  

- **Notion Home**: A new centralized dashboard with widgets, including the My Tasks feature, which pulls tasks from multiple databases into one view.  

- **Charts**: New database views that create visualizations like bar charts, line charts, and pie charts for better data analysis.  

- **Database Buttons**: Button properties in databases enable quick actions, such as time tracking setups.  

- **Notion Sites**: Enhanced website-building capabilities with features like custom domains, SEO settings, and analytics.  

- **Marketplace**: A platform for users to buy, sell, or share templates directly within Notion, with features like template protection and email collection.  

- **Custom Emoji**: Users can now add custom static or animated emojis to their workspaces.  

- **Suggested Edits**: Similar to Google Docs, users can suggest edits to pages, though the feature has some limitations.  

- **Notion AI Upgrades**: Includes PDF/image analysis, global AI shortcuts, and AI connectors for Slack, GitHub, and Google Drive.  

- **Minor Features**: Updates like floating table of contents, sidebar upgrades, URL mentions, image cropping, pinned tabs, and improved search functionality.  

- **Quality-of-Life Enhancements**: New formula functions (e.g., mean, median), rounded checkboxes, personalized page URLs, and commenting on database properties.  

- **Team Contributions**: The speaker’s team released tools like Fly Lighter (an advanced Notion web clipper), Ultimate Brain 3.0 (a productivity system), and Notion Helper (a JavaScript library for the Notion API).  

- **Future Plans**: Upcoming tutorials on spaced repetition and time tracking are in development, along with continued improvements to templates and tools.
