## About

Boson AI controllable text-to-speech with inline emotional tags. Production-grade voice synthesis supporting emotional control and fine-grained prosody manipulation.

Models: https://huggingface.co/bosonai/higgs-audio-v3-tts-4b

---

## Capabilities

- Inline emotional tags for controllable speech synthesis
- Production-grade voice quality for conversational and cinematic work
- Speaker adaptation and fine-grained prosody manipulation
- Open-weight model (4B) available for local deployment

---

## VFX / Filmmaking Use Cases

- Generate emotionally directed voiceovers for character content
- Produce cinematic-quality voice work with emotional control
- Adapt voice to match character emotional states in production
- Fast iteration on voice direction without external talent

---

## How to Run

```bash
pip install transformers
python inference.py --model bosonai/higgs-audio-v3-tts-4b --text 'your text' --emotional 'happy'
```
