## Summary

LongLive is a real-time, interactive video generation model by NVIDIA Research capable of producing up to 240-second sequences with strong temporal coherence and prompt adaptability. It introduces causal attention and KV-recache mechanisms for maintaining consistent generation during live prompting.

## Features

- Frame-level autoregressive video generation
- Causal attention with KV-recache for interactive prompt switching
- Short-window attention and frame-sink techniques for long-term consistency
- Real-time generation (~20.7 FPS) on a single H100 GPU
- Supports INT8 quantization for efficiency

## Use Cases

- Long-form AI video generation for filmmaking, VFX, and storytelling
- Interactive video creation with evolving text prompts
- Real-time prototyping of long-take AI cinematics

## Installation

Requires Python 3.10+, install dependencies via requirements.txt, download pretrained checkpoints from HuggingFace, and run inference scripts. Tested on NVIDIA A100/H100 GPUs.

## Other Info

Developed by NVIDIA Research (NVLabs) and released in 2025 with the paper 'LongLive: Real-time Interactive Long Video Generation'. Optimized for creators who need continuous, coherent AI-generated video sequences for cinematic workflows.
