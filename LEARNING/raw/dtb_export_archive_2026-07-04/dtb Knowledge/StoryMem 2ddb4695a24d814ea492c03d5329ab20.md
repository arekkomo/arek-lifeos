## Summary

StoryMem is an AI framework for multi-shot narrative video generation. It introduces memory-conditioned diffusion, enabling cross-shot consistency so that characters, scenes, and visual styles remain coherent throughout the story. Built on Wan2.2, it can generate minute-long storytelling videos.

## Features

- Memory-to-Video (M2V) conditioning with keyframe memory banks
- Multi-shot video generation with cross-shot coherence
- Integrates Wan2.2 T2V/I2V models with LoRA conditioning
- Includes ST-Bench benchmark for storytelling evaluation
- MI2V and MR2V generation modes for varied workflows

## Use Cases

- AI-driven long-form video storytelling
- Automated storyboarding and previsualization
- Research into memory-based video diffusion models

## Installation

Clone the repository, create a Python 3.11 environment, install dependencies, and download Wan2.2 + StoryMem LoRA models. Use run_example.sh with a JSON script to generate multi-shot videos.
