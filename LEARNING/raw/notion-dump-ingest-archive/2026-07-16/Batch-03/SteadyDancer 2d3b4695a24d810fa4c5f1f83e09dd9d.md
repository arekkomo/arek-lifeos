## Summary

SteadyDancer is the official implementation of 'SteadyDancer: Harmonized and Coherent Human Image Animation with First-Frame Preservation'. It enables high-quality human animation generation from a single reference image and a driving video using an Image-to-Video paradigm that maintains identity consistency and temporal coherence.

## Features

- First-frame identity preservation for consistent animation.
- Image-to-Video paradigm to improve motion coherence.
- Multi-GPU inference support and dataset benchmarks.
- Ready-to-use inference code and model checkpoints.

## Use Cases

- Generate human dance or motion animations from still images.
- Develop and research motion transfer and video synthesis.
- Produce creative AI-driven content for media or research.

## Installation

Clone repo, install dependencies via requirements.txt, download pretrained models, and run inference scripts as documented in README.
