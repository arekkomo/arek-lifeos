## Summary

OmniInsert enables mask-free video insertion by leveraging diffusion transformer models to seamlessly integrate objects or subjects into target video scenes. It removes the need for manual segmentation or masks and ensures motion, lighting, and perspective consistency between source and target.

## Features

- Mask-free video compositing via diffusion transformer
- Consistent lighting, motion, and geometry adaptation
- Works with arbitrary reference videos or images
- Fully automatic, no manual segmentation required

## Use Cases

- VFX and content creation workflows for inserting characters or props into existing footage
- Automating scene compositing for AI video production
- Ideal for filmmakers or creators needing rapid, realistic object insertion

## Installation

Clone repo, install dependencies from requirements.txt, prepare source and target videos, and run provided scripts for video insertion inference.
