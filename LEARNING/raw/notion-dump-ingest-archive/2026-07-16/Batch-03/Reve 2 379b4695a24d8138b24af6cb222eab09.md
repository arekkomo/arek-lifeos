## About

Open-source layout-driven 4K text-to-image generation with Large Layout Models. Enables precise spatial control for complex compositions from natural language prompts.

Paper: https://arxiv.org/abs/2605.17572

---

## Capabilities

- 4K text-to-image generation with Large Layout Models
- Precise spatial control via layout conditioning from natural language
- Multi-reference image conditioning with structural guidance
- Open-source architecture with fine-tuning support

---

## VFX / Filmmaking Use Cases

- Generate concept art with precise composition control
- Create layout-driven storyboards from script descriptions
- Produce reference images with specific spatial arrangements
- Generate style-consistent asset libraries with placement control
