## Summary

Spatia is a video generation framework that maintains spatial and temporal consistency across long video sequences using an updatable 3D scene point cloud as memory. It leverages visual SLAM and dynamic-static disentanglement for stable geometry and motion coherence.

## Features

- Persistent 3D point cloud as spatial memory
- Dynamic-static disentanglement for stable geometry
- Supports explicit camera control via 3D trajectories
- Enables interactive 3D-aware video editing
- Outperforms existing models in spatial/motion consistency

## Use Cases

- Generate long, coherent 3D-aware videos
- Research on memory-augmented generative video models
- Controlled video synthesis and cinematic scene editing

## Installation

Clone the repo, install dependencies (PyTorch, SLAM modules), and run training/inference scripts as outlined in README.
