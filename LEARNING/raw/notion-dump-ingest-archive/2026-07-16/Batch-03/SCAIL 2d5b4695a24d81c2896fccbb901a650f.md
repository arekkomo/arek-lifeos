## Summary

SCAIL (Studio-Grade Character Animation via In-Context Learning) is a framework for generating high-fidelity character animations from reference images and motion sources. It combines diffusion-transformer architectures with 3D-consistent pose representations and context-aware motion reasoning for lifelike animation synthesis.

## Features

- 3D-consistent pose representation for structural fidelity
- Full-context pose injection in a diffusion-transformer model
- Handles large motion variations and multi-character scenes
- Includes pose extraction and rendering tools
- Apache-2.0 licensed with example pipelines and pretrained checkpoints

## Use Cases

- Create studio-quality motion sequences from still images and motion clips
- Develop AI-driven animation and motion transfer workflows
- Research spatio-temporal consistency in video generation
- Prototype real-time character animation pipelines

## Installation

Clone repo and follow provided instructions to install dependencies. Includes scripts for inference, pose extraction, and model checkpoint loading.
