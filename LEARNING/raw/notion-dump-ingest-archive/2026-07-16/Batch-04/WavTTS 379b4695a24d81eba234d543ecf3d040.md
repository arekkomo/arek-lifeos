## About

ByteDance zero-shot text-to-speech generator. High-fidelity voice synthesis from short vocal reference with controllable emotion, prosody, and style.

Project: https://bytedance.github.io/WavTTS/

---

## Capabilities

- Zero-shot voice synthesis from short audio reference
- Controllable emotion, prosody, and speaking style
- High-fidelity output suitable for content production
- ComfyUI integration for node-based pipeline workflows

---

## VFX / Filmmaking Use Cases

- Generate dialogue voiceovers for AI-generated character content
- Clone voice from reference footage for lip-sync pipelines
- Create emotional variations for iterative ADR/voice direction
- Rapid prototyping of audio assets with minimal voice samples

---

## How to Run

```bash
git clone git@github.com:Saganaki22/WavTTS-ComfyUI.git
cd WavTTS-ComfyUI
pip install -r requirements.txt
comfyui --node wavtts --ref_audio voice.wav
```
