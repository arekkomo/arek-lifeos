## Summary

Wan-Alpha is a high-quality text-to-video model developed by WeChatCV capable of producing videos with alpha channels (transparency). It jointly learns RGB and alpha information, allowing seamless compositing and realistic rendering of semi-transparent elements such as hair, smoke, and glass.

## Features

- Text-to-video generation with alpha transparency
- Joint RGB+Alpha diffusion transformer architecture
- Supports fine details like semi-transparent effects
- Includes ComfyUI workflow integration
- Pretrained models available (Wan2.1-T2V-14B, LightX2V)

## Use Cases

- Create transparent-background videos for VFX and compositing
- Generate motion graphics or subject layers directly usable in editing software
- Useful for AI-driven filmmaking, AR, and video content creation

## Installation

Clone repo, create Python 3.11 environment, install dependencies via requirements.txt, download pretrained weights, and run generation scripts with text prompts to produce RGBA frames.
