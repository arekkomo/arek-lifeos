## Summary

Just-Dub-It is a modular AI pipeline that automates video dubbing by chaining speech recognition, translation, text-to-speech, and lip-sync systems to produce multilingual dubbed videos.

## Features

- End-to-end video dubbing pipeline
- Automatic speech recognition (ASR)
- Machine translation integration
- Text-to-speech voice generation
- Lip-sync alignment
- Modular architecture (swap models)
- CLI-based workflow

## Use Cases

- Video localization for global audiences
- Dubbing YouTube and social media content
- Educational content translation
- Building AI dubbing workflows or SaaS
- Rapid prototyping of multimodal pipelines

## Installation

Clone repo, install dependencies, configure ASR/TTS/translation models, and run CLI pipeline on input videos.

## Other Info

Pipeline tool combining multiple AI models rather than a standalone model; useful for practical dubbing workflows.
