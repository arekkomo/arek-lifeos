## Summary

TwinFlow-Z-Image-Turbo is an optimized text-to-image generation model built on the TwinFlow framework. It enables one-step or few-step image synthesis by learning self-correcting flow fields, significantly reducing inference time while maintaining visual quality.

## Features

- One-step or few-step generative inference
- Based on the TwinFlow self-rectified flow framework
- Fine-tuned from Z-Image-Turbo for enhanced speed and stability
- Apache-2.0 licensed, available on Hugging Face
- Compatible with Diffusers library

## Use Cases

- Rapid text-to-image generation
- Research on efficient diffusion and flow-based models
- Integration into low-latency creative pipelines

## Installation

Use via Hugging Face `diffusers` or `transformers` API. Load model with `from_pretrained('inclusionAI/TwinFlow-Z-Image-Turbo')` and generate images from prompts.

## Other Info

Part of the TwinFlow model family by inclusionAI, focusing on efficient generative modeling with minimal inference steps.
