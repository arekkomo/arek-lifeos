## About

Unified framework for video generation that combines an MLLM-based semantic planner with a DiT-based renderer. Reaches first tier among commercial models for video synthesis.

Paper: https://arxiv.org/abs/2605.22344

---

Models: https://huggingface.co/ByteDance/Bernini

---

## Capabilities

- Text-to-video with semantic planning and DiT rendering pipeline
- Image-to-video with temporal consistency and frame control
- Video editing: style transfer, object replacement, scene composition
- Precise control over content, style, pacing, and composition

---

## VFX / Filmmaking Use Cases

- Generate video assets from script descriptions or storyboard images
- Retime or adjust pacing of generated clips dynamically
- Replace foreground/background elements while preserving visual quality
- Match AI-generated assets to project lighting and art direction standards

## How to Run

```bash
git clone git@github.com:bytedance/Bernini.git
cd Bernini
pip install -r requirements.txt
python main.py --prompt 'your prompt' --model ByteDance/Bernini
```
