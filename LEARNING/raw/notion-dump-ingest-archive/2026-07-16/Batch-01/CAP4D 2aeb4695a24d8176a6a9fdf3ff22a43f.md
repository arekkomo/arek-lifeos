## Summary

CAP4D is a generative framework that builds animatable 4D portrait avatars from one or more reference images. It combines a morphable multi-view diffusion model with 3D Gaussian splatting to generate consistent dynamic 3D reconstructions suitable for animation and real-time rendering.

## Features

- Morphable multi-view diffusion model for multi-angle synthesis
- 3D Gaussian splatting for real-time renderable 4D avatars
- Supports 1–100 reference images for varying fidelity
- Allows editing of lighting, expression, and appearance
- Audio-driven facial animation support

## Use Cases

- Generate and animate 3D/4D portrait avatars for filmmaking and VFX
- Create personalized digital doubles from stills or short video
- Useful for virtual production, previsualization, or interactive storytelling

## Installation

Requires Python 3.10, install dependencies from requirements.txt, download pretrained weights and assets, and run provided generation scripts (generate_avatar.sh). GPU with high VRAM recommended.

## Other Info

Developed by Felix Taubner (University of Toronto / Vector Institute / LG) and presented at CVPR 2025. Bridges diffusion-based multi-view generation with animatable 3D avatar construction for use in content creation and VFX pipelines.
