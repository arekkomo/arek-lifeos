## Summary

Ditto is an open-source framework tackling data scarcity for instruction-based video editing by generating a large synthetic dataset (Ditto-1M) to train advanced video editing models like Editto.

## Features

- Synthetic dataset generation pipeline
- Support for training and inference
- Integration with DiffSynth and ComfyUI
- Example scripts and workflows

## Use Cases

Running text instruction video editing workflows, training/editing video models, and integrating AI video editing into creative pipelines.

## Installation

Setup a Python environment (conda), install with pip, download pretrained models from Hugging Face/Drive, and run inference via provided scripts or integrate with ComfyUI.

## Other Info

Academic research project with no official releases yet; licensed under CC BY-NC-SA 4.0 with scripts for dataset generation, model training and inference.
