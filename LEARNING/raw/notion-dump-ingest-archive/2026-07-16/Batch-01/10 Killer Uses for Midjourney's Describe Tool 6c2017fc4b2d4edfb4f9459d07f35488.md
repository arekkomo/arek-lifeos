### **Introduction to the Describe Tool**

- **Purpose:**
    - Learn how to use MidJourney's upgraded **Describe Tool** to convert images into text prompts.
    - Described as a "reverse prompt" feature, ideal for sparking creativity and refining artistic direction.
- **Tool Features:**
    - Analyzes images to generate descriptive prompts.
    - Useful for inspiration, prompt building, and understanding artistic styles.

---

### **How to Use the Describe Tool**

1. **Accessing the Tool:**
    - Type `/describe` in Discord’s message bar and press Enter.
    - Upload an image or paste an image URL.
2. **Output:**
    - Generates four descriptive text prompts for the image.
    - Options:
        - Select individual prompts to edit and refine.
        - Use "Imagine All" to run all four prompts simultaneously.
3. **Enabling Remix Mode:**
    - Type `/prefer remix` to activate the option for editing prompts.
