## Summary

Depth Anything 3 (DA3) is a single-transformer based model that predicts spatially consistent geometry (depth maps, ray maps, optionally camera pose and 3D Gaussians) from arbitrary visual inputs (single-image, multi-view).

## Features

• Single plain transformer backbone
• Depth-ray representation for unified geometry prediction
• Monocular, multi-view and pose-conditioned modes
• Export to multiple formats (glb, ply, npz), CLI and web UI support

## Use Cases

Monocular depth estimation; Multi-view depth and pose estimation; Novel view synthesis / 3D geometry pipelines.
