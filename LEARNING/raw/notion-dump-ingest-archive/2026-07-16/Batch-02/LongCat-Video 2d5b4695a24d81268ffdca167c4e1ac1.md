## Summary

LongCat-Video is an open-source large-scale video generation model by Meituan that supports Text-to-Video, Image-to-Video, and Video-Continuation tasks. It achieves high temporal stability and visual fidelity across long durations, with strong performance on generative video benchmarks.

## Features

- Unified model for text, image, and video-based generation
- Supports long-form video synthesis with minimal quality loss
- Diffusion Transformer architecture with coarse-to-fine inference
- Provides model weights, demo scripts, and inference examples
- MIT-licensed open-source release

## Use Cases

- Create long videos from text or image prompts
- Extend and continue existing video clips
- Research and develop long-form generative video pipelines
- Integrate into AI media generation and content workflows

## Installation

Clone repo and install dependencies from `requirements.txt`. Includes demo scripts: `run_demo_text_to_video.py`, `run_demo_image_to_video.py`, and `run_demo_long_video.py`.

## Other Info

Developed by Meituan LongCat Team. Designed for scalable, efficient, and high-quality video generation up to several minutes long.
