## Summary

Genfocus is an AI-powered generative refocusing framework that allows flexible post-capture depth-of-field control and realistic bokeh effects from a single photo. It leverages a two-stage generative model pipeline combining defocus deblurring and controllable bokeh synthesis for precise optical simulation.

## Features

- Two-stage architecture with DeblurNet and BokehNet
- Generates realistic depth-of-field and custom aperture bokeh
- Text-guided or parameter-based blur control
- Interactive Gradio demo available
- Open-source with Apache 2.0 license

## Use Cases

- Computational photography and image refocusing
- Artistic and cinematic bokeh creation from standard photos
- Research in defocus estimation and generative optics

## Installation

Clone the repo, install Python dependencies, download pretrained model weights, and run the provided Gradio demo for interactive use.
