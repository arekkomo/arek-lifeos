## About

Markerless multi-person motion capture from video. Max Planck Institute system for reconstructing 3D human poses and interactions without wearable sensors.

Paper: https://arxiv.org/abs/2605.03724

---

Models: https://huggingface.co/Max-Planck-Institute-for-Intelligent-Systems/mamma

---

## Capabilities

- Markerless mocap from monocular RGB video (no suits, no sensors)
- Multi-person capability with spatially aware attention mechanism
- 3D motion from single camera without multi-view setups
- Generative 3D avatar creation and fine-grained motion control

---

## VFX / Filmmaking Use Cases

- Capture performance from standard video for CG character animation
- Rapid mocap from on-set reference footage for character rigs
- Generate base poses for multi-character scenes from single take
- Create motion baseplates for refinement in Maya/Blender

## How to Run

```bash
git clone git@github.com:cuevhv/mamma.git
cd mamma
pip install -r requirements.txt
python inference.py --video input.mp4
```
