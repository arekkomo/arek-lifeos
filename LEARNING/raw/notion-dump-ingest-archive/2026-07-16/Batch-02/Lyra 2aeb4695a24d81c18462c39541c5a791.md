## Summary

Lyra is a generative 3D scene reconstruction framework from NVIDIA Spatial Intelligence Lab that distills 3D knowledge from video diffusion models into explicit 3D Gaussian Splatting representations. It enables 3D/4D scene generation from a single image or video input with real-time rendering capabilities.

## Features

- Self-distillation pipeline from video diffusion models
- Supports single-image and monocular video inputs
- Outputs explicit 3D Gaussian Splatting (3DGS) scenes
- Real-time rendering support
- Apache-2.0 licensed

## Use Cases

- Generate 3D/4D scenes for filmmaking, VFX, or virtual production
- Reconstruct 3D environments from iPhone-shot videos for scene visualization
- Use as a bridge between 2D diffusion models and explicit 3D assets

## Installation

Install dependencies from requirements.txt, download pretrained weights from HuggingFace, and use provided scripts (static_sdg.sh, dynamic_sdg.sh) to run inference. Tested on A100/H100 GPUs.

## Other Info

Released 2025 by NVIDIA Spatial Intelligence Lab; represents NVIDIA’s move to distill 3D knowledge from diffusion models into real-time explicit representations; useful for high-end AI filmmaking and VFX workflows.
