## Summary

Lynx is a high-fidelity video generation framework from ByteDance that generates full video sequences from one input image using a diffusion transformer architecture. It integrates ID and Ref adapters to maintain subject identity and spatial detail, producing personalized video motion.

## Features

- Diffusion Transformer-based video generator
- ID-Adapter and Ref-Adapter modules for identity and detail preservation
- Apache 2.0 licensed
- Supports generating subject-specific videos from a single image
- Available in 'full' and 'lite' versions

## Use Cases

- Filmmaking and content creation for generating personalized subject videos
- Rapid video prototyping for VFX and AI-driven animation
- Creating virtual doubles and motion previews from still images

## Installation

Install via requirements.txt, set up Python 3.10 environment, download models into 'models/' directory, and run infer.py with subject image and text prompt inputs.
