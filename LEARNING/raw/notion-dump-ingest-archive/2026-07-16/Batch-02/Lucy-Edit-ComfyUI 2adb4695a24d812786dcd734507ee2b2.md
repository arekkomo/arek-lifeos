## Summary

Lucy-Edit-ComfyUI integrates the Lucy Edit model into ComfyUI, providing instruction-guided video editing with free-text prompts that can change clothing, objects, or entire scenes while maintaining motion and structure.

## Features

- Instruction-based video editing through text prompts
- Preserves motion and composition
- Handles clothing, object, and character edits
- Custom nodes for ComfyUI integration

## Use Cases

- Rapidly prototype video edits with prompts
- Apply style or wardrobe changes in post-production
- Generate alternate takes without manual masking
- Useful for VFX and AI-assisted content creation

## Installation

Install via ComfyUI custom nodes; model weights hosted on Hugging Face under decart-ai/Lucy-Edit-Dev.
