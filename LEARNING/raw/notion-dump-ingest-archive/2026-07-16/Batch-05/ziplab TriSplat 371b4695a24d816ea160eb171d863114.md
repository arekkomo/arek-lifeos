## About

TriSplat reconstructs simulation-ready triangle meshes from sparse (2+) unposed images in a single forward pass. Native triangle primitives load directly into physics engines — no TSDF fusion or Poisson reconstruction.

**GitHub:** [https://github.com/ziplab/TriSplat](https://github.com/ziplab/TriSplat)

**Paper:** [https://arxiv.org/abs/2605.26115](https://arxiv.org/abs/2605.26115)

**Models:** [https://huggingface.co/lhmd/TriSplat](https://huggingface.co/lhmd/TriSplat)

**Project:** [https://lhmd.top/trisplat/](https://lhmd.top/trisplat/)

## Capabilities

- Feed-forward reconstruction from 2+ sparse unposed images
- Direct triangle mesh output — no post-processing pipeline
- Camera pose + intrinsics estimation in same forward pass
- Under 1.3 seconds vs tens-to-hundreds for Gaussian-to-mesh baselines

## VFX / Filmmaking Use Cases

- Reconstruct a real location from iPhone photos into a physics-ready mesh for set extension
- Replace NeRF-based capture with a faster, mesh-native alternative
- Assign PBR materials directly to triangle output in Blender or DaVinci Fusion

## How to Run

```bash
conda create -y -n trisplat python=3.10
pip install torch==2.1.2 torchvision==0.16.2 --index-url https://download.pytorch.org/whl/cu118
pip install -r requirements.txt --no-build-isolation
bash scripts/env/rebuild_extensions.sh
```
