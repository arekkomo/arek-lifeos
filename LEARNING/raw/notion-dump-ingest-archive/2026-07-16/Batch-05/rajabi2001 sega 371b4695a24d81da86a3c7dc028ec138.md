## About

SEGA dynamically rescales RoPE attention based on the latent's spatial-frequency content at each denoising step. Enables stable generation up to 36MP (6144×6144) with no retraining, new weights, or architecture changes.

**GitHub:** [https://github.com/rajabi2001/sega](https://github.com/rajabi2001/sega)

**Paper:** [https://arxiv.org/abs/2605.22668](https://arxiv.org/abs/2605.22668)

**Project:** [https://rajabi2001.github.io/sega/](https://rajabi2001.github.io/sega/)

## Capabilities

- Training-free high-res synthesis for FLUX.1 and Qwen-Image
- Up to 36MP (6144×6144) with multi-GPU
- Outperforms YaRN, DyPE, UltraImage, ScaleDiff, I-Max, HiFlow
- No new params, weights, or architecture changes

## VFX / Filmmaking Use Cases

- Generate print-quality (36MP) reference art or storyboards with FLUX
- Create ultra-high-res texture prompts for 3D/VFX workflows
- Pair with PiD for 4K generation → 8K decode pipeline

## How to Run

```bash
git clone https://github.com/rajabi2001/sega.git
cd sega && pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install -r requirements.txt
cd flux_sega && python run_flux.py --prompt "Your prompt." --height 4096 --width 4096
```
