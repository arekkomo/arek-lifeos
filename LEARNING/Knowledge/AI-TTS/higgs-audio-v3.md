**By:** Boson AI
**Released:** 2026-06-04

## What It Is

Controllable TTS model supporting inline emotional tags. Built specifically for voice AI — designed to speak model responses in the moment with expressiveness that makes an agent feel conversational. Not just reading text, but delivering it with emotion, timing, and prosody control.

---

## Key Architecture

- **Inline emotion control**: Tags within text stream to control emotion, style, speed, pitch, pauses, sound effects mid-utterance
- **Production-grade**: Designed for live conversational voice AI, not just TTS demos
- **Multilingual**: 100+ languages support
- **Single-digit WER on benchmarks**: Competitive accuracy across languages
- **Commercial API + HF weights available**

---

## Capabilities

- Inline emotional/style control via text tags
- 100+ languages
- Voice cloning from audio references
- Prosody, pitch, and pause control within utterances
- Lowest WER on multilingual benchmarks (SeedTTS, CV3, MiniMax, Higgs)
- Commercial API + open source HF weights
