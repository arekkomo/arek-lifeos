# AI Automation Agency (AAA)

A business model built around selling AI automation services to businesses that lack the in-house expertise to build them. Documented across multiple sources in the knowledge base.

## The model

1. Build expertise in AI workflow tools (n8n, make.com, LLM APIs, Claude, GPT)
2. Identify businesses with repetitive, automatable workflows
3. Build and deploy custom automations
4. Charge setup fees + recurring maintenance retainer

## Specializations mentioned

- **AI Automation Specialist** — generalist AI workflow builder
- **AI pipeline builder** — focus on LLM + API integration
- **Content AI pipelines** — automated content generation and distribution

## Business entry paths (from sources)

- Start with one niche (e.g. AI video pipelines for content creators)
- Build a portfolio of automations in that niche
- Expand or productize (sell templates, courses, SaaS)

## Tools commonly used

- [[n8n|n8n]] — workflow automation backbone
- Claude / GPT APIs — LLM reasoning within workflows
- Relevance AI — AI pipeline builder (mentioned as alternative to n8n for AI-heavy flows)
- Make.com — alternative to n8n for simpler workflows

## Critique / reality check

> ⚠️ The "get rich with AI" sources in this cluster are optimistic/promotional. Treat revenue claims skeptically. The underlying model (selling automation services) is real and documented, but timelines and income figures vary widely.
