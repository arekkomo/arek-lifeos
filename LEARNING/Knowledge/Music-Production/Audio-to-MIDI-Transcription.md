# Audio-to-MIDI Transcription

Audio-to-MIDI transcription makes a recording editable as symbolic note data. It is useful for analysis and reconstruction, but MIDI does not retain the full sound design, mix, vocal timbre, or performance nuance of the source audio.

## Uses

- Inspect arrangement and instrumentation in a reference track
- Create an editable starting point in a DAW
- Extract rhythmic/harmonic cues for visual synchronization
- Turn an original recording or jam into a notation/production sketch
