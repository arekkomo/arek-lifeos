# Competitive benchmarks: food + destination

## Important limit

Instagram’s unauthenticated public HTML exposed profile-level follower/following/post counts during this research capture, but not a reliable, reproducible post feed or reach/engagement data. Therefore this page does **not invent cadence, content mix, or engagement rates**. The account-level counts below are a scale reference only, captured 2026-07-18; Connector should run the 12-post census below before making competitive claims.

The scale figures are direct public-profile metadata observed on the linked accounts. They are not endorsements, and all can change. Keep competitors as inspiration and test against One More’s own local audience; do not imitate a large account’s volume or voice.

## 12-post census: Connector’s operational benchmark

Once a month, collect each account’s 12 most recent **original** posts (exclude pinned/reposts when clear):

| Metric | Capture | Formula / decision use |
|---|---|---|
| Cadence | post dates | `(oldest date − newest date) ÷ 11`; classify <2, 2–4, or >4 feed posts/week |
| Format | Reel / carousel / photo | format count ÷ 12; compare to One More’s 45/35/20 launch hypothesis |
| Caption | word count, hook type, CTA type | tally sensory/place/person hook; one versus multiple CTAs |
| Place/partner | location tag and collaborator tag | shows whether local network is a repeatable growth channel |
| Engagement | likes + comments (public when visible) | `engagement rate by followers = (likes + comments) ÷ followers × 100` |
| Quality signals | saves/shares/reach only if disclosed | never estimate these from likes |

**Do not call a static engagement-rate number “current.”** Follower count and post interaction need to be captured on the same day. A public-like/comment rate is only a partial proxy: it excludes saves, shares, watch time and reach, the signals One More should prioritize internally.

## Patterns to borrow—not copy

- Make every food post also answer a place question: *where is this and what kind of day does it belong to?*
- Give proper credit to growers, makers and hosts; a genuine collaborator is stronger than a generic influencer ask.
- Alternate feast/finished-dish images with hands, process, weather, table and arrival so the account sells an experience rather than an isolated plate.
- Build an ownable recurring series: “One More at the table,” “From coast to plate,” or “Sunday service notes.” Use it only after three distinct posts show a repeatable audience response.
