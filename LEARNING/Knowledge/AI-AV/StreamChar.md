# StreamChar (Real-time AI Character Streaming)

**By:** Humanaigc team (Alibaba/Personas group)
**Released:** 2026
**GitHub:** (via project page)

---

## What It Is

Real-time AI character streaming system. Generates and streams animated character video synchronized with speech input, suitable for real-time conversational agents and avatars.

---

## Key Architecture

- **Real-time streaming**: Low-latency generation suitable for live interaction
- **Speech-driven animation**: Character movement and lip sync driven by audio input
- **Continuous streaming**: Generates character video continuously as input stream arrives
- **Alibaba research**: Built by Humanaigc team at Alibaba/Personas group

---

## Capabilities

- Real-time character video generation from speech
- Continuous stream output for live interaction
- Speech-driven lip sync and facial animation
- Low-latency pipeline for conversational agents

---

## VFX / Filmmaking Applications

- **Animated presenter**: Create AI-generated host for virtual productions
- **Interactive character content**: Generate real-time animated characters for VR/AR
- **Digital avatar broadcasting**: Stream avatar-based content presentations
- **Interactive pre-vis**: Real-time animated characters in pre-visualization workflows
- **Educational content**: Generate speaking avatar hosts for instructional content
- **Customer service avatars**: Create animated customer service characters

---

## Requirements

- Speech input (text-to-speech or microphone)
- GPU compute for real-time inference
- Streaming infrastructure for low-latency output
