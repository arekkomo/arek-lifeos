# Stable Layers

**By:** Stability AI
**Released:** 2026
**GitHub:** https://stability-ai.github.io/stable-layers.github.io/
**Project Page:** https://stability-ai.github.io/stable-layers.github.io/

---

## What It Is

Stability AI's tool for converting images into editable transparent layers. Automatically decomposes images into compositional layers that can be individually edited and recombined.

---

## Key Architecture

- **Automatic layer decomposition**: Splits images into meaningful compositional layers
- **Layer-based editing**: Each layer operates independently with transparency
- **Stability AI model**: Built on Stability AI's image decomposition models
- **Editable components**: Layers can be moved, deleted, or modified independently

---

## Capabilities

- Image-to-layers conversion with automatic segmentation
- Transparent layer management
- Layer-level editing and recombination
- Preserves original image quality during decomposition

---

## VFX / Filmmaking Applications

- **Rapid pre-production**: Decompose reference images into layers for shot breakdown
- **Compositing pipeline**: Create editable asset from single images for VFX workflows
- **Texture/lighting exploration**: Modify individual elements for experimentation
- **Background/foreground separation**: Automatic subject isolation for VFX planning
- **Asset reuse**: Convert static references into modular editable files for animation/planning
