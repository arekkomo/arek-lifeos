# Lyra

AI tool that reconstructs 3D environments from video captured on an iPhone, enabling VFX and virtual production workflows without expensive scanning hardware.

## What it does

- Takes ordinary iPhone video as input
- Outputs a 3D reconstruction of the filmed environment
- Designed for VFX scene visualization and virtual production use

## Significance

3D environment capture traditionally requires:
- LIDAR scanners or photogrammetry rigs
- Controlled capture conditions
- Significant post-processing

Lyra commoditizes location scanning: any filmmaker with an iPhone can capture a 3D environment for set extensions, pre-vis, or virtual production reference.
