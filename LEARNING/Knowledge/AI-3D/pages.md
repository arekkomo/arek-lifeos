# PaGeR (Panoramic Geometry Estimation via R)

**By:** ETH Zürich PRS Lab (prs-eth)
**Released:** 2026
**GitHub:** https://github.com/prs-eth/PaGeR
**Paper:** https://pager360.github.io/
**Project Page:** https://pager360.github.io/

---

## What It Is

Panoramic geometry reconstruction model for 360° scene geometry estimation from multi-view inputs. A unified foundation model approach to panoramic 3D understanding.

---

## Key Architecture

- **Multi-view foundation model**: Leverages foundation model architectures for panoramic understanding
- **Unified approach**: Single model for various panoramic geometry tasks
- **Foundation-based**: Built on foundation model training paradigms for generalization

---

## Capabilities

- 360° panoramic geometry inference
- Multi-view input processing
- Unified foundation model for panoramic scene understanding
- Pan-optic scene geometry estimation

---

## VFX / Filmmaking Applications

- **360° VR content**: Generate panoramic geometry from multi-view photography
- **Panoramic pre-vis**: Create 360° scene geometry for VR/AR productions
- **Panoramic environment tracking**: Real-time 360° scene understanding for virtual production
- **Panoramic reconstruction**: Reconstruct entire 360° environments from standard camera inputs

---

## Requirements

- Multi-view image or video input for panoramic capture
- Foundation model compute infrastructure
