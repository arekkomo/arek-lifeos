## The meta-insight: this database built itself

The **n8n YouTube→Notion pipeline** entry is notable: it is the workflow that populated the dtb Knowledge database. It uses Claude to classify and tag each ingested YouTube video across a fixed 12-category taxonomy (AI Video, AI Image, VFX, Filmmaking, Tutorial, AI Automation, LLM, ComfyUI, Diffusion Models, AI, Productivity, Content Creation). This is a real-world agentic automation pipeline in production use.
