# Story2Board

Pipeline that converts **text or visual concepts** into coherent multi-shot storyboard sequences. Automates the creative-to-storyboard step — critical for rapid pre-production in AI-assisted filmmaking where traditional storyboarding is a bottleneck.

## Key Features
- Text/image → structured storyboard conversion
- Maintains narrative continuity across shots
- Generates cinematic shot types and camera positions
- Output usable as generation prompts downstream

## Use Cases
Rapid concept visualization, pitch materials for funding/pitches, and automated pre-production from script or treatment documents. Bridges the gap between written creative direction and visual planning.

> ⚠️ Workflow integration: Story2Board output → `[[CineMaster]]` camera params → `[[Wan2-Open]]` generation per shot → `[[FilmPort]]` pipeline orchestration.
