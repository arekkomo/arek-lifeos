# VACE (Alibaba)

Open-source reference-to-video model from Alibaba's Vision & Computational Intelligence Lab. Generates video conditioned on **reference images** rather than text — ideal for character consistency across shots.

## Key Features
- Character substitution within existing scenes
- Merge multiple reference images in a single generation
- Motion transfer between source and target videos
- High-resolution output support
- Open-source (Apache-licensed)

## Use Cases
Maintaining consistent characters across AI-generated shots — crucial for long-form content production. Replaces manual character design iteration with direct image conditioning.

> ⚠️ Cross-domain: Compare approach to `[[SAMURAI]]` segmentation for post-hoc character extraction from footage.
