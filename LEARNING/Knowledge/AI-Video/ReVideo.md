# ReVideo

AI video transformation/recreation system. Takes existing footage and **re-generates it** with controlled motion and content changes — preserving some structural elements while modifying others. Essentially a structured re-rendering pipeline rather than simple editing.

## Key Features
- Video-to-video transformation with content control
- Selective regeneration of specific video segments
- Motion preservation across style/content changes
- Structured approach replacing brute-force inpainting

## Use Cases
Style-transfer applied to live-action footage, AI-powered scene re-interpretation for creative projects, rapid prototyping of "what-if" visual variations on existing footage.

> ⚠️ Note: This represents an emerging technique — evaluate against `[[SeedVR2]]` (for post-hoc enhancement) and `[[FilmPort]]` (for full production workflow). The video-as-input approach differs from standard text-to-video pipelines.

## Access
[GitHub](https://github.com/ReVideo-remake). Research release with code available for evaluation.
