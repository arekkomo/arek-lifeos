# Magic-1-For-1

Open-source video generation model from the Open-Magic-Video collective. Designed to preserve exact **1:1 pixel ratio** and support cinematic aspect ratios (2.39:1, etc.) in generation — built specifically for filmmakers who need proper frame dimensions without letterboxing or cropping.

## Key Features
- Native cinematic aspect-ratio support from generation start
- 1:1 pixel preservation (no upscaling artifacts)
- Open-source weights available for self-hosting
- Optimized for film production pipelines

## Use Cases
Producing AI-generated footage ready for professional edit compositing without post-hoc resolution adjustment. Critical when working in established film pipeline standards.

> ⚠️ Compare: `[[FilmPort]]` manages multi-model output; Magic-1 focuses on single-model quality optimized for film formats. `[[Wan2.2-Lightning]]` offers speed-first alternative.
