# Open-Sora

Open-source text-to-video model by NUS HPC-AI Lab (hpcaitech/Open-Sora on GitHub). Positioned as the democratized alternative to OpenAI's Sora.

## Capabilities

- Text-to-video generation
- Image-to-video generation (upload image → animate)
- Self-hostable; no API dependency

## Significance

Makes high-quality video generation accessible without proprietary API costs. Important for independent filmmakers and creators who want full control over their generation pipeline.
