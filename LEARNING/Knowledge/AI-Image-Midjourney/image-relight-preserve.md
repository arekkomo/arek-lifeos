# AI Image Relight and Preserve with Detail Integrity

## Overview
Technique for controlling light sources in AI-generated images while preserving existing detail — key to VFX integration workflows where generated elements must match live-action lighting.

## Core Capabilities
- **Light source repositioning** without introducing structural artifacts
- **Specular highlight matching** to match surface material response
- **Shadow realignment** for physically plausible integration
- **Detail preservation** of texture, pattern, and fine-grained features during lighting swaps
- **Directional control** — key/fill/rim relationship adjustments

## VFX Pipeline Integration
Maps directly to DaVinger Resolve's color grading workflow: relighting generated images → match grade live footage. Preserved-detail approach ensures AI elements don't "read" as synthetic when composited into camera plate.

> **Synthesis Note:** This technique bridges Image/Midjourney domain with VFX domain — detail-preserving relight is the equivalent of set extension match-grades where lighting study and HDRI capture ensure virtual elements integrate seamlessly.
