# Midjourney Canvas Editing + Retexturing Techniques

**Source:** Nolan tutorial video via YouTube | Date Added: January 9, 2025
**Original URL:** https://www.youtube.com/watch?v=1WQW55y5E-8

## Key Techniques Covered

### Retexturing Images
Start with a foundational image (photo or MJ-generated), then retexture into different styles/periods:
- Transformed modern kitchen → decrepit needing renovation, snowy igloo castle, futuristic space station
- Applied styles like vintage Polaroids and haunted mansion vibes
- Retexture preserves composition while drastically changing mood/atmosphere

### Expanding Images with Canvas Editing
Shrink main image to add canvas space around it, then prompt expansion:
- Extended suburban house → haunted Halloween night (bats/pumpkins), igloo/medieval castle
- Maintains environmental consistency through context-aware prompting
- Ideal for creating storyboard sequences and environment variations

### Sketch-to-Detailed Image Pipeline
1. Start with smaller aspect ratio (square) to focus MJ's processing
2. Use prompts like "black pen and ink sketch" for dynamic poses
3. Refine with retexture features for stylistic transformation
4. Try styles: Final Fantasy concept art, Fortnite loading screen, cell-shaded anime

### Prompt Crafting Best Practices
- Be descriptive about the ENTIRE scene, not just inserted elements
- Use specific style references from previously successful images
- Lower `--stylize` value for more control over outputs
- Increase `--chaos` for variety in results
- Include setting details in prompts (e.g., "kangaroo fighting in a broken city")

### Consistent Results Checklist
1. Start with clear, uncongested character sheets
2. Use Var Region tool to reposition/edit specific areas only
3. Iterate prompts rather than overloading single attempts
4. Build characters on smaller canvases before expanding outward
5. Leverage free tools (Photop for manual fixes) alongside MJ

> **Synthesis Note:** Canvas editing + retexture workflows map directly to compositing node networks in VFX — canvas = your viewer context, retexture = material/shader swaps, Pan = camera framing shifts between shots. This is essentially the same control paradigm as working with layers in DaVinci Fusion or Blender's Compositor.
