# Midjourney Character Consistency via Canvas Editing + Var Region

**Source:** YouTube tutorial | Date Added: January 9, 2025
**Original URL:** https://www.youtube.com/watch?v=2klDgkK2YUs

## Core Method: CSVr (Character Sheet + Var Region)

1. Generate a character sheet with multiple poses in a single image
2. Use "Var Region" tool to isolate and edit specific character elements
3. Modify individual poses while preserving facial features and key identity markers

### Examples Demonstrated
- Created young boy in blue sweater/black pants → repositioned on chair via Var Region
- Adjusted gestures: playing guitar, sitting on sofa, holding items
- Var Region excels at adding dynamic poses and minor corrections (fixing hands, replacing missing limbs)

### Changing Backgrounds
- Select character with Var Region → insert new backgrounds (forest, cityscape)
- Quality depends on scale/detail in prompt matching original perspective
- Alternative: remove backgrounds via Photop or similar tools for custom environment integration

## Pan Method for Scene Expansion
Pan tool extends left/right/up/down, filling based on prompt context:
- Extended boy riding horse scene to include environmental details
- Added items (leather jackets, books), changed environments (café, desert)
- Challenges: occasional body proportion distortions fixable through refinement

## Creative Application: Story Building
Built narrative around single character across diverse activities (guitar, skating, painting):
- Start with clear prompts to establish baseline identity
- Reuse Var Region anchors for consistency across scene changes
- Iterate rerolls and prompt adjustments for quality improvement
- Use free tools (Photop, ClipDrop uncrop) for manual corrections post-generation

> **Synthesis Note:** This workflow mirrors the character rigging pipeline in 3D animation. Character sheet = bind pose reference, Var Region = vertex selection + transform, Pan = camera framing between shots. The consistency challenge maps directly to maintaining UV/texture integrity across multiple render passes in VFX compositing.
