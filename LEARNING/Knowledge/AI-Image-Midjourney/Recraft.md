# Recraft (AI Image Generation)

**Recraft.ai** — AI image generation platform with unique **vector-aware outputs**. Unlike most T2I models that only produce raster images, Recraft can generate SVG vector graphics alongside bitmaps, making it especially useful for designers who need scalable brand assets.

## Key capabilities
- Vector (SVG) + raster output from same model
- Style-guided consistent multi-image generation
- Editable layer outputs for design workflow integration
- Focused on professional design use: logos, icons, illustrations, UI assets

## Positioning relative to Midjourney
Recraft targets the **design/production** workflow rather than artistic exploration. Where MJ excels at creative discovery and photorealism, Recraft serves as a practical brand asset generator with output formats (SVG, editable layers) that integrate into Figma/Illustrator pipelines.
