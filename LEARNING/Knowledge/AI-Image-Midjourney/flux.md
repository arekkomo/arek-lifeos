# Flux

AI image generation model positioned as a competitor to [[midjourney]] and Stable Diffusion. Offers image generation, editing, and customization in a single system.

## What it is

Flux is a text-to-image (and image editing) model. Differentiates itself from Midjourney by being available for integration/customization rather than purely as a hosted service.

## Key capabilities

- AI image generation from text prompts
- Image editing (modify existing images via prompts)
- Customization — fine-tuning or style adaptation for specific use cases

## Competitive position

| | Midjourney | Stable Diffusion | Flux |
|---|---|---|---|
| Access | Discord / web | Open-source (local) | API / integration |
| Editing | Limited | ComfyUI ecosystem | Native |
| Customization | Style refs (`--sref`) | LoRA / DreamBooth | Built-in |
