# FLUX Image Edit

## Overview
FLUX series model adapted for controlled image editing rather than generation from text. Enables structured transformation pipelines where input images undergo targeted modification while maintaining structural coherence.

## Key Applications
- **Inpainting** — targeted region replacement with coherent fill
- **Style transfer** — apply consistent aesthetic across image set
- **Compositional edits** — object addition/removal within context-aware rendering
- **Quality enhancement** — resolution upsampling, detail refinement while preserving intent

> **Synthesis Note:** FLUX Image Edit maps to the retiming/stabilization tools in Resolve's edit page but in visual domain — you're not adjusting timecode, you're adjusting pixel intent. Critical for VFX pipeline work where generated assets must be iterated rapidly from a base plate.
