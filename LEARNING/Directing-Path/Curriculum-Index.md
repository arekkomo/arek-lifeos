# Directing Curriculum

> **Goal:** Build Arek from skilled VFX Supervisor to confident film director, using AI tools as the accelerant.
> **Time horizon:** 12–18 months of consistent evening and weekend work.
> **Constraint:** Peak hours belong to Image Engine. Curriculum fits into compressed creative windows.

---

## The Thesis

You already know how a frame is *built*. What you're learning is how to *decide* what a frame *means*.

A VFX Supervisor controls the image. A director controls *why* the image is what it is — the intent behind every compositional, tonal, and temporal choice. The gap between the two is smaller than most people think, but it requires a specific mental shift: from executing a visual to authoring one.

AI tools collapse the production barrier. With Runway, Kling, and ComfyUI, you can direct without a crew. That's not a workaround — it's the strategy.

---

## Curriculum Structure

Each module follows the same pattern:

```
Concept       → What is the directorial idea? Why does it matter?
Exercise      → Practical drill. Fast and repeatable.
Apply         → Use the concept on a real project.
Reference     → Directors who do this exceptionally well.
```

Progress is tracked here and in the Portfolio folder.

## Cadence

- **Daily:** 15–30 min concept review or exercise during morning session
- **Evening:** Execution — apply the concept using AI tools
- **Weekly:** One completed exercise minimum
- **Monthly:** Strategist check-in — progress review, next module decision
