# MidJourney Canvas Editing + Retexturing Techniques

Source: ["MidJourney's NEW Feature TRICKS"](YouTube tutorial by Nolan)

## Core workflows covered

### Retexturing Images
- Start with any base image (photo or MJ-generated prompt) and retexture to entire new styles/time periods. Examples include transforming a modern kitchen to a decrepit ruin, snowy igloo castle, or futuristic space station. Also applied Polaroid and haunted-mansion aesthetics.
- Best for: rapid style exploration, concept iteration, mood board creation.

### Expanding via Canvas Editing
- Shrink the main image on the canvas to create empty margin space, then prompt around the edges to expand the environment while maintaining thematic/visual consistency with the original subject. Examples include extending a suburban house into multiple narrative environments (haunted mansion / medieval castle).
- Best for: environmental storytelling without re-doing the core composition.

### Sketch-to-Detail Pipeline
1. Begin with a small-canvas sketch (e.g., "black pen and ink" prompts for dynamic poses).
2. Use retexture layer to apply styles like Final Fantasy concept art, cell-shaded anime, or Fortnite loading screen aesthetics.
3. Iterate toward the desired rendering style.

### Background/Character Composition Tips
- Describe the entire scene in prompts rather than focusing solely on inserted elements (e.g., "a giant jack-o-lantern sits **in front of the house**" instead of just naming the object).
- Use quotation marks around titles/text layers for clearer rendering.
- Pan directions (left/right/up/down) fill into new areas based on the active prompt — useful for adding items or changing environments across a scene series.

## Prompting refinements highlighted
| Tip | Why it works |
|---|---|
| Lower `--stylize` value | More deterministic control over output style intensity |
| Increase `--chaos` | Greater variety in outputs for brainstorming phase |
| Style reference from successful previous images | Carries visual DNA forward across iterations |
