## About

Real-time AI character streaming and speech-driven animation. Alibaba/Personas research for continuous animated speech-driven avatars with synced lip motion.

Paper: https://arxiv.org/abs/2605.14470

---

## Capabilities

- Real-time character streaming with speech-driven animation
- Dynamic face model optimization for expressive facial motion
- Continuous animated speech synchronized with generated audio
- End-to-end character animation from audio input

---

## VFX / Filmmaking Use Cases

- Generate speech-driven digital humans for interactive content
- Create real-time talking avatar streams for virtual production
- Sync facial animation to voiceover or live audio feeds
- Build animated character pipelines for real-time rendering

---

## How to Run

```bash
git clone git@github.com:humanaigc/StreamChar.git
cd StreamChar
pip install -r requirements.txt
python run.py --audio input.wav --output animation.fbx
```
