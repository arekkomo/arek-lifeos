## Summary

BindWeave by ByteDance is a framework for generating subject-consistent videos through multimodal large language model (MLLM) reasoning and Diffusion Transformer (DiT) generation. It ensures consistent identities and temporal coherence in videos based on prompts and reference images.

## Features

- Cross-modal reasoning with MLLM-DiT architecture
- Maintains subject identity across frames
- Supports multi-subject interaction videos
- High temporal coherence and visual fidelity

## Use Cases

- Generate consistent videos of specific subjects from reference images
- Create multi-entity scenes from natural language prompts
- Integrate into VFX pipelines for controllable, identity-stable generation

## Installation

Clone repo, run build_env.sh, download pretrained Wan2.1 I2V 14B and BindWeave weights, configure and run inference scripts.
