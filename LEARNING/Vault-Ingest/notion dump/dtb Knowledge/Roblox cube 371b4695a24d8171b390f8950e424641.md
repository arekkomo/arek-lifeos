## About

CubePart generates multi-part 3D meshes where each semantic part is a separate, structurally complete mesh driveable by animation, physics, and behavior scripts. SIGGRAPH 2026.

**GitHub:** [https://github.com/Roblox/cube](https://github.com/Roblox/cube)

**Paper:** [https://arxiv.org/abs/2605.28763](https://arxiv.org/abs/2605.28763)

**Models:** [https://huggingface.co/Roblox/cubepart](https://huggingface.co/Roblox/cubepart)

**Demo:** [https://huggingface.co/spaces/Roblox/cubepart-demo](https://huggingface.co/spaces/Roblox/cubepart-demo)

**Project:** [https://cubepart.github.io/](https://cubepart.github.io/)

## Capabilities

- Open-vocabulary part schemas at inference time
- Text prompt + schema → coherent multi-part mesh
- Also accepts existing mesh for decomposition
- Variable granularity (2, 4, or 8 parts on same object)
- 462K assets dataset, 2.02M parts (11× larger than PartVerse-XL)

## VFX / Filmmaking Use Cases

- Generate rigged-ready characters with pre-separated limbs
- Create props with independent moving parts from text alone
- Decompose AI-generated holistic meshes (Tripo etc.) into parts for rigging

## How to Run

```bash
python -m cube3d.generate \
  --gpt-ckpt-path model_weights/shape_gpt.safetensors \
  --shape-ckpt-path model_weights/shape_tokenizer.safetensors \
  --prompt "A jellyfish-themed race car"
```
