## Summary

SVG-T2I is the official PyTorch implementation of a scalable text-to-image latent diffusion model built on top of Visual Foundation Model (VFM) representations. It achieves competitive image generation quality by performing diffusion in feature space, removing the need for a variational autoencoder.

## Features

- Diffusion directly in VFM feature space (e.g., DINOv3 embeddings)
- Training, inference, and evaluation pipelines provided
- Pretrained models for multiple resolutions up to 1024×1024
- Uses diffusion transformers and visual encoder backbones
- Apache-2.0 open-source release

## Use Cases

- Research in representation-based diffusion modeling
- High-quality text-to-image synthesis
- Benchmarking generative performance (GenEval, DPG-Bench)
- Foundation for multimodal and editing models

## Installation

Clone repo and follow the setup instructions for training/inference; supports PyTorch with pretrained checkpoints.
