## Summary

UltraShape-1.0 is a scalable diffusion-based framework for high-quality 3D shape generation. It employs a two-stage pipeline combining coarse shape synthesis and detailed geometric refinement, supported by watertight data curation for robust training and evaluation.

## Features

- Two-stage diffusion pipeline (coarse + fine refinement)
- Watertight data preprocessing for clean meshes
- Voxel-based fine geometry refinement with positional encoding
- Scalable generation suitable for large datasets
- Python-based workflow with pretrained models and demos

## Use Cases

- Generate high-fidelity 3D assets
- Research in scalable 3D diffusion modeling
- Benchmarking for geometric synthesis pipelines

## Installation

Clone the repository, set up a Python environment, install PyTorch and required dependencies, then run coarse and fine generation scripts with pretrained weights.
