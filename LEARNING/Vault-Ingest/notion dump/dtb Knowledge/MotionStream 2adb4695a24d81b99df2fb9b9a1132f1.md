## Summary

MotionStream is a real-time, streaming video generation system enabling interactive control of motion and camera trajectories. Built on an autoregressive causal transformer with attention sinks and rolling KV cache, it can generate continuous, coherent videos with minimal latency.

## Features

- Real-time streaming video generation at ~29 FPS
- Autoregressive causal transformer with attention sinks
- Interactive motion and camera trajectory control
- Rolling KV cache for long-horizon video coherence

## Use Cases

- Interactive video prototyping and VFX previsualization
- Real-time motion-based content generation
- Filmmaking use cases needing immediate visual feedback
- Motion transfer and animation control
