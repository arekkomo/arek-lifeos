## Summary

AniX is a research system for natural language-driven animation of 3D characters inside 3D Gaussian Splatting (3DGS) environments. It generates temporally coherent videos by controlling characters’ actions and camera movements using text commands, enabling interactive scene animation.

## Features

- Natural language control of 3D character actions
- Integration with 3D Gaussian Splatting scenes
- Temporally coherent video generation
- Supports camera movement and scene interaction
- Fine-tuned autoregressive generator for motion consistency

## Use Cases

- Interactive 3D character animation and video generation
- Research in multimodal (text-to-video) control
- Previsualization and AI-assisted storytelling

## Installation

Clone the repository, install dependencies, and run demo scripts following README instructions. Requires pretrained checkpoints for motion and scene synthesis.
