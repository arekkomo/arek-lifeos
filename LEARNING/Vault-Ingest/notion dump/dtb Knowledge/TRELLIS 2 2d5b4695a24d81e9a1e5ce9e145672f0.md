## Summary

TRELLIS.2 is an open-source generative AI model from Microsoft for transforming 2D images into detailed 3D assets. It introduces O‑Voxel, a sparse voxel representation that captures fine geometry and material detail efficiently. The model produces meshes with PBR materials—color, roughness, metalness, and opacity—ready for 3D rendering engines like Blender or Unreal.

## Features

- Generates 3D models from single images using a 4B-parameter AI model.
- O‑Voxel representation handles complex topology and fine detail.
- Outputs PBR-textured meshes compatible with Blender, Unity, Unreal.
- GPU-optimized (NVIDIA H100 achieves ~3 s per 512³ render).

## Use Cases

- Create 3D assets rapidly for games, films, and VR/AR.
- Use for product visualization or digital twin generation.
- Research tool for studying 3D generative modeling architectures.

## Installation

Clone repo, install dependencies with `pip install -r requirements.txt`, run demo with provided sample image or your own. Requires CUDA-compatible GPU.
