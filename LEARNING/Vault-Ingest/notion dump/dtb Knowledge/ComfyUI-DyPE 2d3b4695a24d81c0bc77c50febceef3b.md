## Summary

ComfyUI-DyPE is a custom node extension for ComfyUI that integrates Dynamic Position Extrapolation (DyPE), allowing diffusion transformer models like FLUX, Qwen Image, and Z-Image to produce ultra-high-resolution outputs (4K and beyond) directly in ComfyUI workflows.

## Features

- Plug-and-play ComfyUI node for DyPE.
- Supports FLUX, Qwen Image, Nunchaku, and Z-Image architectures.
- Generates 4K+ ultra-high-resolution images.
- Fine-grained DyPE hyperparameter control.
- No extra inference overhead beyond base model run.

## Use Cases

- Add native ultra-high-resolution capabilities to ComfyUI.
- Experiment with DyPE scaling in visual node pipelines.
- Enhance diffusion model outputs for AI art and design workflows.

## Installation

Install via ComfyUI Manager or clone repo into ComfyUI/custom_nodes/ and restart ComfyUI.
