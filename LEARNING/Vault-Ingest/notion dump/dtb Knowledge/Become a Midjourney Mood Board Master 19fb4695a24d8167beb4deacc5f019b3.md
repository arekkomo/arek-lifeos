### **Summary**

*The speaker shares various tips and techniques for effectively using mood boards in MidJourney. They cover troubleshooting issues, optimizing personalization settings, using void prompts to test styles, adjusting the stylize value for better control, and creating workflows to streamline the process. They also discuss experimenting with different image aspect ratios, using text-heavy mood boards to generate consistent text-based images, and leveraging shortcuts in Discord to automate testing.*

---

### **Key Takeaways**

If a shared mood board code doesn’t work, try using "d-p" instead of "profile" in the prompt.  

To temporarily disable personalization in a prompt, use "d-p done," and to test the regular algorithm, use "--p none."  

Void prompts (symbols instead of words) help test a mood board’s style rather than specific subjects or settings.  

Clicking the arrow next to a mood board name on the create page allows quick access for adjustments.  

The stylize value (--s 1,000) controls how much influence the mood board has on the generated images, but higher values may override prompts.  

Trying mood boards in "style raw" can yield unique and interesting results.  

Mood boards can contain up to 100 images, but using fewer images can lead to more color consistency, while more images create diverse palettes.  

Lowering the stylize value (--s 40-60) can help override dominant color palettes in a mood board.  

Negative prompting can help remove unwanted dominant colors.  

Adding successful generations back into the mood board can improve diversity and maintain a consistent style.  

Having two tabs open—one for generating and one for the mood board—can streamline workflow.  

Creating mood boards with different aspect ratios helps MidJourney generate more varied results.  

Mood boards with text-heavy images can improve consistency when generating new images with text.  

Using a style reference from an existing image can help build a mood board with a consistent aesthetic.  

The "remix strong" button allows users to maintain a style while changing the subject in generated images.  

Exploring random profiles on the personalization homepage can provide inspiration, though codes must be manually noted.  

Using Discord’s "prefer option set" command allows users to create shortcuts for testing different aspect ratios and parameters, saving time.
