## Summary

DyPE (Dynamic Position Extrapolation) is the official implementation of a research method that enables pre-trained diffusion transformer models to generate ultra-high-resolution images beyond their training resolution by dynamically adjusting positional encodings during inference.

## Features

- Adjusts positional encodings dynamically for better ultra-high-resolution output.
- Official implementation with MIT license.
- Works with existing diffusion models like FLUX.
- Includes ready-to-run script run_dype.py.

## Use Cases

- Generate 4K+ images from pre-trained diffusion transformers.
- Research on positional extrapolation and scaling in diffusion models.
- High-detail content creation and AI art workflows.

## Installation

Clone repo, create a Python/conda environment, and install dependencies via requirements.txt. Run main script with prompt and output settings.
