## Summary

MoCha is an end-to-end video character replacement framework that eliminates reliance on structural guidance (pose or depth). It generates consistent results across frames using only a single mask and unified conditions.

## Features

- Full video character replacement using a single mask.
- No need for explicit structural guidance like pose/depth.
- Multi-reference support for identity fidelity.
- Ready inference code for custom video replacement.

## Use Cases

- Replace characters or actors in existing videos.
- Video post-production and AI-driven editing.
- Research in generative video synthesis and character transfer.

## Installation

Clone the repo, install dependencies, download checkpoints, and run inference_mocha.py with your input video and mask.
