## Summary

EgoEdit is an open research framework by Snap Research that enables real-time egocentric video editing. It includes a curated dataset, a low-latency autoregressive editing model (EgoEdit-RT), and benchmarking tools for instruction faithfulness and temporal stability under rapid camera motion.

## Features

- EgoEditData: ~100k egocentric video edit pairs with object replacement/removal
- Real-time editing model achieving ~38fps on single GPU
- EgoEditBench: benchmark for temporal consistency, hand-object preservation, and edit accuracy
- Instruction-driven editing pipeline optimized for AR/first-person use
- Public dataset and evaluation scripts provided

## Use Cases

- AR and wearable camera video editing
- Instruction-based video manipulation research
- Benchmarking temporal stability in first-person video models
- Real-time editing for immersive media and social apps

Clone repo and follow README setup for dataset download, environment configuration, and benchmark evaluation. Inference scripts for EgoEdit-RT model included.
