## Summary

DeepGen is an open-source research-oriented framework for generating videos from text prompts using diffusion-based techniques, with a focus on temporal consistency and controllability.

## Features

- Text-to-video generation
- Diffusion-based video modeling
- Temporal consistency across frames
- Modular and extensible architecture
- Prompt-based conditioning
- Research-friendly implementation

## Use Cases

- AI video generation experiments
- Prototyping Sora-like systems
- Research in generative video models
- Creative content generation
- Testing diffusion-based video pipelines

## Installation

Clone repository, install dependencies, set up GPU environment, and run provided scripts for training or inference.

## Other Info

Early-stage project; more suitable for research and experimentation than production use.
