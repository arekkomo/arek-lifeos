## Summary

Hunyuan3D-Part is a Tencent-developed toolkit that performs 3D part segmentation and generation using two modules: P3-SAM for semantic part segmentation and X-Part for structure-coherent part synthesis. It enables creators to edit, augment, or regenerate mesh components at the part level.

## Features

- P3-SAM: 3D semantic segmentation for meshes
- X-Part: structure-aware part generation
- Works on generic or AI-generated meshes
- Includes pretrained weights via HuggingFace
- Modular architecture supporting both segmentation and generation

## Use Cases

- Segment and generate 3D parts for VFX or game assets
- Automate modular 3D asset creation workflows
- Useful for AI-assisted 3D content pipelines and digital asset libraries

## Installation

Clone repo, install dependencies listed in requirements.txt, download pretrained weights from HuggingFace (tencent/Hunyuan3D-Part), and run P3-SAM or X-Part scripts as per README.
