## 🔥 Top Picks for Arek's Domains

### AI Agents & Multi-Agent Architecture

**SwarmResearch: Orchestrating Coding Agents for Open-Ended Discovery** [arXiv 2607.02807](https://arxiv.org/abs/2607.02807)
- **What:** Orchestrator-subagent harness where a Shepherd Agent steers a population of Search Agents, each with local context in their own git branch. Adapts parallelism at different search depths.
- **Result:** Better solutions on 13/15 tasks vs. serial and parallel baselines through higher-level exploration.
- **Why it matters:** Addresses the convergence problem in long-running coding agents that get stuck in one approach. Directly relevant to multi-agent orchestration patterns used in autonomous development workflows.

**Object-Centric Environment Modeling (OCM) for Agentic Tasks** [arXiv 2607.02846](https://arxiv.org/abs/2607.02846)
- **What:** Organizes agent experience into executable object-centric model: Python classes define environment entities/mechanisms (object knowledge), reusable interaction patterns import and use those objects (procedure knowledge). Online reflection + verification after each episode.
- **Why it matters:** Moves beyond free-form textual memory toward structured, verifiable world models for agents. Progressive knowledge disclosure — inspect signatures first, read source only when needed.

**VERITAS: General-Purpose Replication Tool for Scientific Research** [arXiv 2607.02931](https://arxiv.org/abs/2607.02931)
- **What:** CLI coding agents extract paper claims, run methodology while resolving issues, judge each claim against experiment evidence. Returns importance-weighted Replication Score + severity-rated fix log + patched codebase.
- **Result:** State-of-the-art performance on CORE-Bench and ReplicationBench (65 papers across CS, social science, medicine, astrophysics), surpassing Claude Code baselines.
- **Why it matters:** First general-purpose agent-driven replication tool — not just a benchmark-with-companion-agent but actually usable for independent research verification.

**ASK in the Dark: Uncertainty-Gated LLM Assistance under Partial Observability** [arXiv 2607.02686](https://arxiv.org/abs/2607.02686)
- **What:** Supplies RL agents with trajectory-aware context (partially revealed map, visited positions, action history) + structured CoT reasoning for SLM guidance.
- **Key finding:** Qwen3.5-2B matches/exceeds Qwen3.5-4B — prompt design and selective gating dominate the impact of model scale. On DoorKey: 89%→93%; FourRooms: 53%→70%.
- **Why it matters:** Demonstrates that small models with good context can rival larger ones for agent guidance tasks.

### Embodied AI & Multimodal Agents

**iFLYTEK-Embodied-Omni** [arXiv 2607.02542](https://arxiv.org/abs/2607.02542)
- **What:** Unified multimodal foundation model jointly modeling vision (video + image), language, and action. Brain-cerebellum architecture: VLM + video generation = high-level planning brain; action generation = low-level cerebellum that converts subgoals into executable action chunks.
- **Why it matters:** End-to-end embodied AI without cascaded pipeline bottlenecks. Four-stage progressive training strategy could inform multi-modal agent design.

### Video Generation & Detection

**SPLIT: Training-Free AI-Generated and Partially Edited Video Detection** [arXiv 2607.02886](https://arxiv.org/abs/2607.02886)
- **What:** Detects both fully generated AND partially edited videos using patch tokens from frozen vision encoder via Two-step Temporal Roughness (TTR) and Local Spatial Motion Incoherence (LSMI). Service-aligned evaluation at FPR=0.1%.
- **Why it matters:** State-of-the-art fake recall at strict thresholds while robust to post-processing. Relevant as AI video generation becomes more sophisticated — detection arms race continues.

**BDLM Mamba: Hybrid Block Diffusion with Partial Bidirectionality** [arXiv 2607.02805](https://arxiv.org/abs/2607.02805)
- **What:** Combines efficient attention (Mamba mixing) + block-level parallel generation (diffusion). Restricts reverse Mamba scan to active denoising block for exact KV caching across blocks.
- **Result:** 19.7x throughput of full-sequence DiffuMamba at 65K tokens, 3.7x BDLM attention at 262K tokens.
- **Why it matters:** Architecture-level efficiency gains for long-context generation — applicable to video and audio diffusion pipelines.

### LLM Safety & Alignment

**Oyster-II: RL for Constructive Safety Alignment in LLMs** [arXiv 2607.02914](https://arxiv.org/abs/2607.02914)
- **What:** Moves beyond refusal-based alignment to constructive (response-oriented) safety using Zero-RL + multi-stage strategy. Addresses SFT limitations: insufficient OOD generalization and safety CoT over-generalization on benign queries.
- **Result:** Cross-scale performance comparable to Qwen3-Max and Qwen3.5-397B on safety dimensions.

### Tool Use & Multi-Agent Systems

**CoACT: Action-Preserving Observation Compression for Coding Agents** [arXiv 2607.02911](https://arxiv.org/abs/2607.02911)
- **What:** Compresses agent observations by checking whether compressed obs induces same next action as raw obs (Next-Action Preservation). Reduces token consumption by 33% while maintaining task effectiveness on SWE-bench Verified.

**SovereignNegotiation-Bench** [arXiv 2607.02814](https://arxiv.org/abs/2607.02814)
- **What:** Multi-turn benchmark for delegated personal-agent negotiation under privacy, consent, evidence grounding, and institutional asymmetry constraints. 240 scenarios, 14 baselines, 13,440 trajectories.
- **Key finding:** Agreement-maximizing baselines have low user utility and high privacy/consent risk. Agreement success alone is insufficient for user-owned agents.

**CoC-Seduce: Rhetorical Injection Attacks on LLM Adjudicators** [arXiv 2607.02802](https://arxiv.org/abs/2607.02802)
- **What:** Multi-agent adversarial benchmark testing rule adherence in semi-open textual game environments. Pseudo-Logic is the dominant attack vector across all 20 tested models. Neither model scale nor explicit reasoning mechanisms confer adjudication robustness.
