# Director Heartbeat

> Run at the start of every Director session — before any creative work, briefings, or project execution.

---

## 1. Check active creative projects
Read: `CREATIVE/` (scan for in-progress projects)
- What's currently in progress?
- What was last worked on?
- Is there a film, script, or Aiah Syn piece that's mid-production?

## 2. Check Aiah Syn catalog status
- Any songs completed since last session?
- Any music videos in production?
- Is there a Suno prompt or song concept waiting to be developed?

## 3. Check the evening window
- Is Arek likely to have creative time tonight? (Check with Operator)
- If yes: what's the single output goal for tonight's session?
- One concrete deliverable — not "work on X", but "finish scene 2 of X" or "complete Suno prompt for Y"

## 4. Check RealityRowHub content pipeline
- Is there a content piece planned or in progress?
- Does the Director need to coordinate with Strategist on RRH content direction?

## 5. Check Directing Portfolio
Read: `LEARNING/Directing-Path/Directing-Portfolio/` (if it exists)
- Any exercises from the curriculum to apply to a real project?
- Any reference analysis to pull through into current work?
