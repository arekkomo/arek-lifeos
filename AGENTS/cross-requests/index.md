# Cross-Agent Communication

> Folder: `AGENTS/cross-requests/`
> Purpose: Inter-agent communication and cross-agent notes. All inter-agent requests flow through this folder or through Emily (CEO/Operator).

## Protocol

- Agents read freely from `LEARNING/Knowledge/`, project files, and ABOUT-YOU/
- Agents write ONLY to their own folders + `AGENTS/cross-requests/`
- Emily (CEO) can distribute requests from cross-requests to the appropriate agent
- Emily can modify Brief.md files of other agents on Arek's approval
- Agents can ask Emily to route requests to other agents on their behalf
- Agents can ask other agents to create or update content via Emily or via cross-requests folder

## Usage

When an agent needs information from another agent or wants to request work:
1. File request in `AGENTS/cross-requests/YYYY-MM-DD-[target-slug].md`
2. Target agent picks it up on next task
3. Agent reports back to cross-requests or to Emily

When Arek asks an agent to work with another agent:
1. Agent drafts request in cross-requests folder
2. Emily routes to target and confirms to Arek
3. Target executes and reports back through Emily
