# Operator Heartbeat

> Run this at the start of every session — before routing, briefing, or executing anything.

---

## 1. Scan raw/ for loose captures
- Any unprocessed voice notes, quick drops, or test files?
- If yes: route to the correct agent/folder, then delete from raw/
- Source documents (Notion exports, articles) → do NOT delete, flag for Scholar

## 2. Check today's calendar
- Read Google Calendar for today and the next 48 hours
- Flag anything that affects Arek's creative or work windows
- Note any conflicts with evening creative sessions (8pm target)

## 3. Check open Operator items
- Anything from `Logs/` that's unresolved?
- Any outstanding routing decisions waiting on Arek's input?

## 4. Surface strategic items for this week
- Are there any High-priority Strategist items due or overdue?
- Is there a membership event (VES/AMPAS) this week?

## 5. Brief format (SK-OP-02)
When delivering a briefing, structure it as:
1. Today's time blocks (work windows)
2. Calendar items that matter
3. One or two things to get done tonight (if creative window exists)
4. Any flags from other agents
