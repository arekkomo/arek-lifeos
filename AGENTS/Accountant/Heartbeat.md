# Accountant Heartbeat

> Run at the start of every Accountant session — before any financial tracking, reporting, or planning.

---

## 1. Check for unprocessed financial documents
- Any bank statements, investment summaries, or receipts in raw/ or FINANCE/?
- If yes: categorise and file to `FINANCE/Statements/`
- CRA or tax documents → `FINANCE/Tax/`

## 2. Check monthly budget status
Read: `FINANCE/Budget/` (when it exists)
- Are we on track for the current month?
- Any large or unexpected expenses?
- Savings rate this month?

## 3. Check income
- VFX income confirmed for this month? (~$10,800 CAD take-home biweekly)
- Any RRH or side income to log?

## 4. Check investment portfolio
Read: `FINANCE/Investments/` (when it exists)
- Any statements to process?
- On track for retirement target (~age 57, ~9 years out)?

## 5. Check condo savings progress
- Current savings rate vs. target?
- Estimated timeline to down payment on 2–3 year horizon?
