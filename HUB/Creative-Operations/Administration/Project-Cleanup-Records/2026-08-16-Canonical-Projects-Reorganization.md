# Canonical Projects Reorganization — 2026-08-16

## Outcome

`CREATIVE/` now has three working subfolders:

- `Projects/` — one canonical home per creative project
- `Inspirations/` — incoming references and sparks
- `Library/` — reusable material and studio reference resources

## Consolidations

- **Fog:** `SONG/` and `MUSIC-VIDEO/` now live inside `Projects/Fog/`.
- **Little M:** `SONG/` and `MUSIC-VIDEO/` now live inside `Projects/Little-M/`.
- Film, song, music-video, short, and YouTube-type containers were removed.
- Project review, cleanup records, and the Notion mirror were moved into `Library/`.
- Every canonical project folder has a root `Project-Brief.md`.
- macOS Finder/resource-fork artifacts were removed.

## Future Rule

Create every new project at `CREATIVE/Projects/<Project-Name>/`; use component folders inside it instead of creating domain-level project containers.
