# Creative Library

> A future-facing bank of reusable ideas and concepts. **Project-specific work stays in its project folder.** Operational records live in `HUB/Creative-Operations/`.

## How to use it

- Add concepts that can serve more than one future project.
- Use the five curated craft categories for proven moments, techniques, and references.
- Use the typed Notion-import folders as an idea bank—not as active project storage.
- Promote an item into `CREATIVE/Projects/<Project-Name>/` only once it has a chosen project and next output.
