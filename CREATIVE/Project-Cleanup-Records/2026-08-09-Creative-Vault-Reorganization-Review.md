# Creative Vault Reorganization Review

## Purpose
Separate real projects from story/song/script seeds and production reference, then maintain a truthful execution queue. No imported record becomes a live project merely because it is detailed.

## Recommended operating model
- **Active:** a concrete output is being made now; cap at three creative tracks.
- **Development:** a defined project with a clear next deliverable, but not currently in the weekly execution queue.
- **Paused:** intentionally held; retain the reason and revival trigger.
- **Idea Stash:** standalone seeds, concepts, fragments, or exploratory work with no current commitment.
- **Reference / Production Asset:** characters, shots, prompts, style references, tutorials, and other supporting material—not projects.
- **Archived / Merged:** cancelled work, duplicates, or material superseded by another canonical project.
