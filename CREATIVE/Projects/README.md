# Projects

Each folder here is the **single canonical home** for one creative project.

- Start with `<project-name>_brief.md`.
- Every project file is flat and follows [[../Project-File-Schema|Project File Schema]], except episodic projects, which use `EPISODES/EP01/`, `EPISODES/EP02/`, and so on.
- Do not create project-type folders elsewhere in `CREATIVE/`.
- See [[../Operating-Rules|Creative Project Operating Rules]] for the full system.
