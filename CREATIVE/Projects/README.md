# Projects

Each folder here is the **single canonical home** for one creative project.

- Start with `<project-name>_brief.md`: it is the master context, treatment, reference, asset/voice, production-notes, and decision file.
- Add only the project files needed from the five-file system: `_brief`, `_plot_outline`, `_script`, `_song`, `_scene_shot_breakdown`.
- Every non-episode file is flat and follows [[../Project-File-Schema|Project File Schema]]. Episodic projects alone use `EPISODES/EP01/`, `EPISODES/EP02/`, and so on.
- Do not create standalone storyboards, treatments, production notes, references, asset bibles, scene breakdowns, or component folders.
- Do not create project-type folders elsewhere in `CREATIVE/`.
- See [[../Operating-Rules|Creative Project Operating Rules]] and [[../RRHub-Creative-Project-Contract|RRHub Creative Project Contract]] for the complete read/write system.
