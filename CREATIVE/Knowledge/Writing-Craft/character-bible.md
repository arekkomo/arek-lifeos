# Character-Bible

## Definition
The continuity and performance authority for a character’s dramatic engine, behavior, arc, and visual invariants.

## Pipeline job
Create during development; use it to align writing, direction, casting/voice, design, and AI continuity.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Dramatic engine: objective, obstacle, stakes, contradiction
- Arc and relationships
- Performance language and playable tactics
- Visual continuity and reference assets
- Scene triggers and allowed variation

## House writing rules
- Write behavior, not diagnosis.
- Separate invariant identity from scene-specific state.
- Use a few high-signal visual anchors rather than generic mood adjectives.

## Quality gate
- [ ] Objective, obstacle, and change are clear.
- [ ] At least three playable behavioral choices exist.
- [ ] Key relationships name pressure.
- [ ] Visual invariants and permitted variation are explicit.

## Starter template
```markdown
## Dramatic engine
## Arc and relationships
## Performance language
## Visual continuity
## Scene triggers
```
