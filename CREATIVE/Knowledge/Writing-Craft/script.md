# Script

## Definition
The executable scene-level blueprint of what the audience can see and hear: action, dialogue, narration, and sound in production order.

## Pipeline job
Write after the treatment is stable. It becomes the story authority for scene, shot, asset, and edit planning.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Title / draft context
- Sluglines or timecoded sequence headings
- Filmable action lines
- Character cues and dialogue / voiceover
- Essential transitions, captions, music, and sound cues
- Production flags and continuity entities

## House writing rules
- Write only what can be seen or heard.
- One action paragraph normally carries one visual beat.
- Enter late and leave early unless duration itself matters.
- Keep prompts, seeds, and generation chatter out of the script.
- Use consistent character, location, costume, and prop names.

## Quality gate
- [ ] Each scene has a visible or audible change.
- [ ] A producer can identify cast, locations, props, VFX/AI, sound, and rights flags.
- [ ] It can be timed before expensive generation.

## Starter template
```markdown
## SCENE S01 — INT./EXT. LOCATION — TIME
Action.

CHARACTER
Dialogue.

[Production flag: AI/VFX/rights/continuity]
```
