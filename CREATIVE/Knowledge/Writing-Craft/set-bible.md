# Set-Bible

## Definition
The visual-world and geographic authority for a recurring location or set.

## Pipeline job
Establish before boards and shots that depend on repeatable place identity.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Story function
- Geography, zones, sightlines, and axes
- Design language: architecture, material, color, wear
- Light and time states
- Continuity invariants, linked props, and references

## House writing rules
- Start with what the place does dramatically.
- Describe what a camera can register.
- Separate fixed identity from allowed variants.
- Use diagrams when prose cannot prove geography.

## Quality gate
- [ ] Entrances, exits, eyelines, and power shifts can be staged.
- [ ] Light variants retain place identity.
- [ ] Hero props link to their Prop Bible.

## Starter template
```markdown
## Story function
## Geography
## Design language
## Light and time states
## Continuity and assets
```
