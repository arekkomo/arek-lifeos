# Prop-Bible

## Definition
The authoritative record for story-significant and continuity-sensitive objects.

## Pipeline job
Use for any prop that carries plot information, a repeated visual identity, or a required interaction.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Stable prop ID and narrative function
- Ownership and state timeline
- Visual specification
- Interaction, orientation, safety, and clearance
- References, variants, and prohibitions

## House writing rules
- Describe close-up identifiers and scale, not generic categories.
- Track owner, location, and state by scene.
- Link to set and character records without duplicating ownership.

## Quality gate
- [ ] First/last required appearance is known.
- [ ] State and orientation remain clear.
- [ ] Brand, weapon, food, safety, and clearance flags are visible.

## Starter template
```markdown
## Narrative function
## Ownership and state timeline
## Visual specification
## Interaction and safety
## References and variants
```
