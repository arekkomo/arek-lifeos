# Storyboard

## Definition
A sequential visual prototype that communicates selected frames, screen progression, composition, action, and transitions.

## Pipeline job
Use after the story and alongside shot planning to test geography, rhythm, and continuity before costly work.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Sequence intent
- Numbered frames with thumbnail/image and caption
- Action, transition, duration, and optional sound
- Continuity anchors
- Open questions and linked shot breakdown

## House writing rules
- One frame conveys one decisive screen event.
- Caption motion, sound, transition, or reversal that the image cannot show.
- Use the same Sxx.SHxx IDs as the linked shot breakdown.
- Do not treat panels as a technical coverage list.

## Quality gate
- [ ] Frame order follows the current script.
- [ ] Geography and escalation are reconstructable.
- [ ] Every panel corresponds to a shot entry where needed.

## Starter template
```markdown
## Sequence intent
### S01.SH01 — Frame label
- **Image:**
- **Action / caption:**
- **Transition / duration:**
- **Continuity anchor:**
```
