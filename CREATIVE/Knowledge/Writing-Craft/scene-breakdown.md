# Scene-Breakdown

## Definition
A scene-by-scene interpretive map that turns the approved script into dramatic, spatial, and continuity logic.

## Pipeline job
Create from the script before coverage planning. It tells the shot breakdown what the scene must accomplish.

## Metadata
Use the shared project frontmatter: `type`, `title`, `project`, `stage`, `version`, and `updated`. Add `source:` when the document is directly paired to a script; keep the canonical file inside its project folder.

## Required sections
- Scene ID, script reference, and runtime
- Function, POV, and objective
- Conflict / pressure and dramatic turn
- Emotion expressed through behavior
- Staging / blocking
- Space, continuity, and sound state
- Audience information and coverage intention
- AI / production implications and risks

## House writing rules
- Use observable playable verbs.
- State a before → after turn.
- Treat movement, distance, eyelines, and props as story grammar.
- Do not introduce a new story event absent from the script.

## Quality gate
- [ ] Every scene names function, pressure, turn, staging, continuity, and production implications.
- [ ] No entry is merely a synopsis or abstract mood label.
