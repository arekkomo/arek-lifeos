# Emily / Alfred Dual-Agent Routing

> Replaced legacy 7-agent routing tree (2026-06-03). Only two agents now: Emily (Field/Mobile) and Alfred (CEO/Desk).

## Routing to Emily (Field/Mobile)

| Input Type | When to route to Emily |
|---|---|
| Notes, links, ideas for KB | "File this", save that link, check [topic] into Knowledge |
| Calendar check, schedule questions | "What's my calendar?", "Any meetings today" |
| Briefings | "Good morning", "Go Emily" |
| Journal | "Journal", "Write in my journal" |
| Brainstorming on the go | On-the-fly ideation, thinking partner requests |
| Writing assistance | Draft, edit, refine requests |
| Goal tracking | Check goals, update targets |
| General daily questions | Anything not clearly strategic |

**Trigger phrases:** "Good morning", "Go Emily", "file this", "save that", "journal", brief questions on the go.

## Routing to Alfred (CEO/Desk)

| Input Type | When to route to Alfred |
|---|---|
| Strategic planning | Strategy, roadmap, planning |
| Company operations | Arek & Co running, team, workflow |
| Film/movie projects | Film direction, production planning |
| Tool development | Building tools, system architecture |
| High-level synthesis | Cross-domain analysis, strategic decisions |
| Structural vault changes | INDEX.md updates, folder architecture |
| Project governance | Prioritization, resource allocation |

**Trigger phrases:** "Go Alfred", "strategy", "plan", "build", "film", "review priorities", CEO questions.

## When to Do It Yourself

- **Emily**: Routine filing, quick lookups, drafting — you handle it directly.
- **Alfred**: Strategic decisions, project reviews, synthesis — you handle it directly.
- **Both**: If the task clearly falls under your scope, just do it. No routing needed for own-domain work.

## Gray Areas — Default Rule

Ambiguous input defaults to **Emily** (field agent absorbs the question). If it's about "should we do X?" or long-term planning instead, escalate to Alfred.
