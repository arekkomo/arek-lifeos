# Coach Domain Skill Files

Created 2026-06-06. These 5 skills cover all of the Coach's domain areas.
They are detailed instructions (not vault stubs). Each is a self-contained SKILL.md.

## coach-fitness-tracking
- 5x/week schedule (Mon-Fri), 45-60 min sessions
- Push/Pull/Legs/Arms/FullBody split structure
- Progressive overload protocol (2.5kg increments at top of rep range)
- Injury prevention: shoulder warm-up mandatory, core/back priority
- Tracking: PRs, undertrained muscle groups, frequency drops

## coach-nutrition-tracking
- Daily macro estimation (manual + AI photo vision)
- Targets: ~2,300 kcal, 145-155g protein, 35-40g fibre
- Dietary constraints: meat max 2x/week, lactose soft-avoid
- Weekly meal plan + grocery list (every Friday)
- Storage: /HEALTH/Nutrition-Plan/YYYY-WW-Meal-Plan.md

## coach-body-composition
- Periodic analysis (every 1-6 months)
- Process: upload consistent photos → AI vision analysis → compare → propose adjustments
- Baseline capture on first session

## coach-sleep-recovery
- 2-hour sleep latency is the #1 recovery blocker
- Intervention: screen cutoff 60min before bed, cool room, no caffeine after 2pm, magnesium glycinate
- Recovery flags: HRV trending down 3+ days → deload; sleep <5.5h → reduce intensity
- Correlate sleep with gym performance
- Apple Health (HRV, sleep duration) or manual fallback

## coach-health-intelligence
- Cross-check all recommendations against Scholar's research
- Monitor: B12 (HIGH PRIORITY — tenofovir + reduced meat), Vitamin D, Omega-3, magnesium, fibre
- Bone density monitoring (tenofovir long-term use)
- Store contradictions in /HEALTH/Health-Knowledge/contradictions/
