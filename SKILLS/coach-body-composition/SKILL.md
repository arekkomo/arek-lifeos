# SK-CO-03 — Body Composition

**Agent:** The Coach
**Status:** Active
**Version:** 2.0

## Description
Periodic (every 1–6 months) visual analysis of body composition through progress photos. Compare to previous analyses and propose targeted adjustments.

## Process
1. Arek uploads comparison photos (front, side, back — consistent lighting and posing)
2. AI vision analysis: visible changes in muscle definition, fat distribution, proportion
3. Compare to previous analysis
4. Propose specific adjustments to training and nutrition based on observations
5. Save analysis to /HEALTH/Body-Composition/YYYY-MM-Analysis.md

## Storage
- Folder: `/HEALTH/Body-Composition/`
- Naming convention: YYYY-MM-Analysis.md

## Goal Visual
Lean, proportional physique — primary targets are abdominal fat reduction and shoulder/back muscle development.

## Baseline
First session should capture baseline. Compare all subsequent analyses to it.
